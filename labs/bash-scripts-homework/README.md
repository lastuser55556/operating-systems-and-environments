# Домашнее задание: Bash, 20 задач

Все файлы предназначены для Ubuntu. Запуск: `chmod +x *.sh`, затем `./имя.sh`.

1. `./hello.sh` — пользователь, HOME и дата.
2. `./check.sh` — OK. Без `./` команда `check.sh` обычно не находится, потому что текущий каталог отсутствует в PATH. Можно вызвать `./check.sh` или `bash check.sh`.
3. `./script.sh`, `bash script.sh`, `sh script.sh` — первые два используют Bash; `sh` игнорирует shebang и запускает скрипт в sh. В Ubuntu `/bin/sh` обычно dash, поэтому `$BASH_VERSION` будет пустым.
4. `./perm.sh`; затем `chmod 700 perm.sh && ./perm.sh`. Права 700: rwx только у владельца.
5. `./task05.sh один два три` — параметры, включая последний `${!#}`.
6. `./task06.sh` — переменные и подстановка.
7. `./task07.sh` — PID и сохранённый код возврата.
8. `./task08.sh` — арифметика Bash для целых чисел; частное целочисленное, деление на ноль обрабатывается.
9. `sudo apt install bc` (если нужно), затем `./task09.sh` — 3.33 и 1024.
10. `./task10.sh` — ядро, свободное место и количество обычных файлов в /etc рекурсивно.
11. `./task11.sh` или `./task11.sh Анна` — Гость или переданное имя.
12. `./task12.sh` — без export дочерний bash выводит пустое значение, с export — secret.
13. `./task13.sh` — Bash сообщает об ошибке изменения readonly-переменной; обычная TEMP удаляется через unset.
14. `./task14.sh` — ошибка, если CONFIG не задана или пуста; `CONFIG=demo ./task14.sh` — успешный запуск.
15. `./task15.sh` — проверка git; при отсутствии вывод в stderr и exit 1.
16. `./task16.sh` — изменение регистра и длина строки.
17. `./task17.sh` — несуществующий путь возвращает ненулевой код (обычно 2), `/` — 0.
18. `./task18.sh` — скрытый ввод пароля. Это учебная имитация авторизации, без реальной проверки пароля.
19. `./task19.sh` — ввод за 5 секунд, иначе таймаут.
20. `./task20.sh` — массив слов с номерами.
