# Процессы в Linux

## Цель работы

Изучить команды Linux для просмотра процессов, запуска процесса в фоновом режиме, просмотра заданий, завершения процесса и изменения приоритета.

## Выполненные команды

Создание рабочей папки:

```bash
cd ~
mkdir process-lab
cd process-lab
```

Просмотр процессов:

```bash
ps
ps -e
ps aux | head
pstree | head
```

Запуск процесса в фоновом режиме:

```bash
sleep 300 &
jobs
ps
```

Поиск процесса:

```bash
ps aux | grep sleep
```

Завершение процесса выполняется командой `kill` с указанием PID процесса:

```bash
kill 4486
jobs
```

Просмотр процессов в реальном времени:

```bash
top
```

Запуск процесса с измененным nice-значением:

```bash
nice -n 10 sleep 100 &
ps -o pid,ni,cmd | grep sleep
```

## Результат

Были выполнены команды для просмотра процессов, запуска фонового процесса, просмотра списка фоновых заданий, поиска процесса по имени, работы с `top` и запуска процесса с измененным значением `nice`.
