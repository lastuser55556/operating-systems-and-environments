Администрирование Linux

/etc/passwd — файл с информацией обо всех пользователях системы. В каждой строке хранится имя пользователя, UID, GID, информация о пользователе, домашний каталог и командная оболочка. Сам пароль обычно здесь не хранится, вместо него стоит x.

/etc/shadow — защищенный файл, в котором хранятся хеши паролей пользователей и информация о сроках их действия. Здесь указано, когда пароль менялся, сколько он действует и когда учетная запись должна быть заблокирована.

passwd — команда для смены пароля пользователя и управления сроком его действия.

passwd имя_пользователя


Права администратора

root — суперпользователь Linux, имеет максимальные права в системе.

su (switch user) — команда для переключения на другого пользователя, в том числе на root.

sudo — позволяет выполнить команду с повышенными правами без постоянного перехода в root.

Добавление пользователя в группу sudo:

usermod -aG sudo имя_пользователя

/etc/sudoers — файл с правилами использования sudo. Для его редактирования используется visudo.

root ALL=(ALL:ALL) ALL

Эта строка означает, что root может выполнять любые команды с любыми правами.


Мониторинг Linux

Мониторинг позволяет следить за состоянием и производительностью системы, нагрузкой процессора, памятью, дисками и процессами.

df — показывает свободное и занятое место на дисках.

du — показывает, сколько места занимают файлы и каталоги.

free — показывает использование оперативной памяти и swap.

iostat — показывает статистику работы дисков и операций ввода-вывода.

mpstat — показывает загрузку процессора и отдельных ядер.

vmstat — показывает статистику оперативной памяти, процессора, процессов и дисков.

w — показывает пользователей, которые сейчас находятся в системе, и информацию об их работе.

htop — показывает процессы и состояние системы в реальном времени, также позволяет управлять процессами.

В htop:

Mem — использование оперативной памяти.
Swp — использование swap.
Tasks — количество процессов.
Load average — средняя нагрузка на систему.
Uptime — время работы системы с момента запуска.


Мониторинг сети

ip monitor — показывает сетевые события в реальном времени: изменение IP-адресов и маршрутов, включение и отключение сетевых интерфейсов.
