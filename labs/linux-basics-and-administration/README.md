GNU/Linux это операционная система с открытым исходным кодом. Linux это ядро системы, которое отвечает за работу компьютера, а GNU это набор программ и утилит. Вместе они образуют GNU/Linux. Ubuntu это один из дистрибутивов GNU/Linux

Для установки Ubuntu скачивается ISO образ. В VirtualBox создается виртуальная машина, выделяется оперативная память, процессор и место на диске. Затем подключается ISO образ, запускается установка Ubuntu, выбирается язык и основные настройки, создается пользователь и пароль. После установки виртуальная машина перезагружается и Ubuntu готова к работе



инод - структура в файловой системе линукс которая хранит информацию о владельце
