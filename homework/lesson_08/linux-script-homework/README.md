# Скрипты Bash Linux

Решены задания 1–20 из документа «ДЗ скрипт». Все решения собраны в `tasks.sh`; номер задания передаётся первым аргументом.

```bash
bash tasks.sh 1
bash tasks.sh 5 один два три
CONFIG=production bash tasks.sh 14
```

Проверка и запуск выполнены в контейнере Debian Linux с Bash 5.2. Для задания 9 в Linux устанавливается пакет `bc`.
