# Bash Условия Циклы Функции

## Содержание

В работе выполнены 15 заданий из приложенного методического документа: четыре задания на условия, шесть заданий с циклами и пять заданий с функциями.

## Запуск

Нужен Bash. Из папки работы запустите нужный файл:

```bash
bash scripts/01_number_sign.sh
```

| Задание | Скрипт | Что делает |
|---|---|---|
| 1 | `01_number_sign.sh` | Определяет знак числа |
| 2 | `02_file_check.sh` | Проверяет существование, тип и чтение файла |
| 3 | `03_grade.sh` | Преобразует оценку в текст через `case` |
| 4 | `04_leap_year.sh` | Проверяет високосный год |
| 5 | `05_multiples.sh` | Выводит числа от 1 до 100, кратные 3 или 5 |
| 6 | `06_multiplication_table.sh` | Строит таблицу умножения |
| 7 | `07_sum_to_n.sh` | Считает сумму от 1 до N |
| 8 | `08_files_by_size.sh` | Сортирует файлы текущей папки по размеру |
| 9 | `09_password.sh` | Даёт три попытки ввести пароль `secret` |
| 10 | `10_tree.sh` | Рисует ёлочку из звёздочек |
| 11 | `11_is_even.sh` | Использует функцию `is_even` для чётных чисел |
| 12 | `12_max_of_three.sh` | Находит максимум из трёх чисел |
| 13 | `13_factorial.sh` | Считает факториал рекурсией |
| 14 | `14_count_files.sh` | Подсчитывает файлы без поддиректорий |
| 15 | `15_check_hosts.sh` | Проверяет доступность трёх хостов |
