# Практическая работа: обработка ошибок в Bash

Решены 12 задач из документа «Ошибки.docx». Скрипты расположены в каталоге [scripts](scripts/), по одному файлу на задачу. Для повторения проверок из корня репозитория:

```bash
python3 labs/bash-error-handling/run_checks.py
```

Результат выполнения: **23/23 проверок прошли**. Коды возврата и результаты по каждой задаче приведены в [results.md](results.md). Ненулевые коды в тестах ошибочных входных данных ожидаемы.

В задаче 4 Bash завершает выполнение при обращении к необъявленной переменной с `set -u` на этапе раскрытия переменной. Это не вызывает `trap ERR`, поэтому сообщение выводится ловушкой `EXIT`; ловушка `ERR` также установлена для обычных ошибок команд. В задаче 6 тесты посылают реальные `SIGINT` и `SIGTERM` процессу, проверяют код завершения и удаление временного каталога.
