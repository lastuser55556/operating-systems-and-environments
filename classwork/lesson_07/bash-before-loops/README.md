# Bash: примеры до раздела «Циклы»

По презентации `скрипты.pptx`, слайды 2–26. Каждый пример расположен в `scripts/`, его фактический вывод после запуска Bash — в `outputs/`, изображение вывода — в `screenshots/`.

Запуск: `bash scripts/02_first_script.sh` (аналогично для остальных файлов). Все файлы проходят `bash -n`.

Слайды 3–4 описывают установку права на запуск файла со слайда 2: `chmod +x scripts/02_first_script.sh`, затем `./scripts/02_first_script.sh`. Слайды 9, 12, 17, 19 и 25 содержат синтаксис и справочные таблицы, а не отдельные программы.

Исправлены явные опечатки в примерах: переменная `value1` на слайде 18 заменена на `val1`; `user =` на слайде 20 заменено на `user=`; `cd $ mydir` на слайде 26 заменено на `cd "$mydir"`. Для демонстрации существующего пользователя на слайдах 14 и 20 берётся текущий пользователь, для проверки каталога на слайде 26 создаётся локальный `sample_home`. Пример слайда 21 намеренно сохраняет отсутствие кавычек вокруг переменной со значением из двух слов, чтобы показать ошибку `[: too many arguments`; слайд 22 показывает исправление. Изображения получены из реального вывода выполненных скриптов в этой среде; это не снимки окна Ubuntu пользователя.
